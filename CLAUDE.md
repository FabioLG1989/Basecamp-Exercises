# CLAUDE.md

## QAF first, always

This repo is initialized with the [Qubika Agentic Framework (QAF)](https://thisisqubika.github.io/qubika-agentic-framework/).
Every task goes through QAF before anything ad hoc:

1. **Start from QAF's context.** Claude Code also loads `.claude/CLAUDE.md` (generated by
   QAF). For anything beyond a one-line change, read the LLM wiki router
   `docs/llm-wiki/CLAUDE.md`, then only the wiki pages it points you to, before reading code.
2. **Use a QAF skill when one fits.** Check `.claude/skills/` first and run the matching
   skill instead of improvising the workflow:
   - New work: `/create-sdd-ticket` → `/create-implementation-plan` → `/implement-ticket`
   - Stress-test a plan: `/grill-me` · Keep the diff minimal: `/lean-code`
   - Reviews and feedback: `/pr-reviewer`, `/security-review`, `/apply-pr-feedback`
   - Failures: `/troubleshoot` · Bugs: `/report-bug`
   - Wiki upkeep after structural changes: `/wiki-refresh`
3. **Use QAF's agents** in `.claude/agents/` (planner, implementer) for planning and
   multi-file changes.
4. **Fall back to ad-hoc work only when no QAF skill applies**, and say so in one line.
5. **Don't hand-edit QAF output** (`.claude/CLAUDE.md`, `.claude/skills/`, `.claude/agents/`,
   `.claude/framework-config.json`, `docs/llm-wiki/`): re-initialization regenerates it.
   Project-specific rules belong in this file or in AGENTS.md.

### Re-initializing QAF

The framework clone is local only (`qubika-agentic-framework/` is gitignored). From the repo
root, with `claude` logged in:

```bash
git clone https://github.com/thisisqubika/qubika-agentic-framework.git
MODEL_TIER=advanced ./qubika-agentic-framework/scripts/initialize-project.sh --provider claude
```

Known issue: QAF's `service-realness-classifier` runs on Haiku even in the `advanced` tier
and marks this repo (notebooks, `package = false` in `pyproject.toml`) as "not a real
service", so the init aborts with no services. Before running it, set that agent's alias
to `opus-latest` under `tiers.advanced.agents` in
`qubika-agentic-framework/orchestration/config/model-config.json` (local clone only).

## GitHub: use `gh`, never the GitHub MCP

All GitHub work (PRs, issues, reviews, checks, merges, API calls) goes through the `gh`
CLI. Don't use GitHub MCP tools, even when they're available.

## Claude settings in `.env`

Scripts and notebooks read these names from `.env` (or the shell, which wins) through
`basecamp_setup.py`:

- `ANTHROPIC_API_KEY`: the key.
- `ANTHROPIC_MODEL`: the workhorse model (`MODEL` in every notebook). Defaults to
  `claude-sonnet-5`. The fast (Haiku) and big (Opus) comparison models stay fixed.

Never print, quote or commit their values.
